# Anti-Patterns – Lesson 04

Bearbeiten Sie die zugeteilten Fälle in Ihrer Moodle-Gruppe; teilen Sie die praktische Arbeit bei fünf Personen in ein Zweier- und ein Dreierteam auf. Verwenden Sie die acht Abschnitte als gemeinsame Struktur und stellen Sie Situation, beobachtbares Anzeichen, Ursache und überprüfbare Gegenmaßnahme in insgesamt fünf Minuten pro Gruppe vor. Ein Fehlerexperiment in einer Übungskopie ist von einem tatsächlich vorgefundenen Fehler zu unterscheiden.

- [AP09 Infrequent Check-In](AP09-infrequent-check-in.md)
- [AP10 Bottleneck Commits](AP10-bottleneck-commits.md)
- [AP11 Scheduled Builds](AP11-scheduled-builds.md)
- [AP12 Impeding action with minimal feedback](AP12-minimal-feedback.md)
- [AP13 Spam Feedback](AP13-spam-feedback.md)
